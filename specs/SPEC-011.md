# SPEC-011: Testing Pipeline

## Objective
Implement an automated, deterministic test results processor capable of parsing Maven Surefire and Failsafe XML reports into strongly typed `TestResult` domain objects.

## Context
Rather than having an LLM read thousands of lines of unparsed Maven stdout, deterministic tools must parse the exact XML reports generated by JUnit 5/Surefire, isolating failing tests, assertions, and stacktraces.

## Scope
- XML parser for `target/surefire-reports/TEST-*.xml`.
- Aggregator for test count, failures, errors, skipped, and execution durations.
- Distinguishes between unit test failures and integration test failures.

## Non-scope
- Running the Java tests directly locally (delegated to `ExecutionBackend`).

## Functional Requirements
- FR-11.1: Parse all Surefire XML report files found in the test execution payload.
- FR-11.2: Extract failed test class, method name, assertion message, and stacktrace.
- FR-11.3: Generate a consolidated `TestResult` domain model with `passed: bool`.

## Schemas
```python
class TestCaseResult(BaseModel):
    classname: str
    name: str
    time: float
    status: Literal["PASSED", "FAILED", "ERROR", "SKIPPED"]
    failure_message: str | None = None
    stacktrace: str | None = None

class TestResult(BaseModel):
    passed: bool
    total: int
    passed_count: int
    failed_count: int
    skipped_count: int
    duration_ms: int
    cases: list[TestCaseResult]
```

## Security Considerations
XML parsing must be protected against XML External Entity (XXE) vulnerabilities using `defusedxml` or safe `xml.etree.ElementTree` parsing without external entity resolution.

## Observability
Records total tests executed, test pass percentage, and aggregate test execution time.

## Failure Handling
Malformed XML falls back to regex-based extraction from stdout logs.

## Acceptance Criteria
- Parses standard Maven Surefire XMLs into structured `TestResult` objects.

## Tests
- `test_surefire_parser_with_passing_suite`
- `test_surefire_parser_with_failures_and_errors`
- `test_surefire_parser_xxe_resilience`

## Definition of Done
Deterministic Surefire parser verified against standard Maven XML reports.
